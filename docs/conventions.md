# Convenciones

- Nombres de archivos y rutas en minúsculas con guiones cuando corresponda.
- Documentación en Markdown, con títulos jerárquicos y ejemplos reproducibles.
- Cada requisito tendrá identificador estable (`RF-###` o `RNF-###`).
- Un requisito debe expresar una sola necesidad verificable.
- Los criterios de aceptación usarán el formato Dado/Cuando/Entonces.
- Los cambios deben conservar formato, codificación UTF-8 y terminadores existentes.
