# Plan del proyecto

## Fases

1. Levantar, validar y priorizar requisitos.
2. Diseñar la arquitectura PaaS y el contrato de ejecución segura.
3. Construir un MVP con editor y terminal en una misma pantalla.
4. Probar accesibilidad, responsive, seguridad y comportamiento funcional.
5. Desplegar el MVP y documentar operación y evolución.

## Alcance inicial

El MVP permitirá escribir código C++, solicitar su compilación y visualizar la salida o los errores en una interfaz con dos apartados: IDE y terminal.
